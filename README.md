# WN8 Motors Website

Standalone landing page for WN8 Motors — mobile mechanic and engine specialist service in Skelmersdale, Lancashire.

## Deployment

Deploy to **wn8motors.co.uk** — any static hosting (Vercel, Netlify, Cloudflare Pages).

```
wn8-motors-site/
├── index.html          # Single-page site (all CSS inline, no build step)
├── img/
│   ├── logo.png            # Full logo (1024x1024)
│   ├── logo-header.png     # Header/footer logo (200x200)
│   ├── hero-engine.jpg     # Hero image (800x420, 86KB)
│   ├── og-share.png        # Social share image (1200x630)
│   ├── apple-touch-icon.png
│   ├── favicon-48x48.png
│   ├── favicon-32x32.png
│   ├── favicon-16x16.png
│   └── favicon.ico
└── README.md
```

## To deploy on Vercel

1. Create new repo from this folder
2. Import to Vercel
3. Framework: None (static)
4. Output directory: `.` (root)
5. Connect domain: wn8motors.co.uk
